## 🚀 Proyectos y Sistemas Destacados

### 🏥 Modernización de Sistema de Seguros (Tecservin Ltda.)
- Migración del sistema de seguros **Sysprev** de PHP a **Python con Flask**, rediseñando tanto el backend como el frontend con **Tailwind CSS**.
- Integración de servicios **SOAP/XML** con **OracleDB/PostgreSQL**.
- Funcionalidad en tiempo real y optimización del rendimiento para una mejor experiencia de usuario.

### 📦 Desarrollo de Módulo ERP (ALES Industries C.A.)
- Extensión de **ERP Dynamics AX 2012** con módulos personalizados usando **MorphX/X++**.
- Migración de bases de datos y configuración de entornos **.NET/CIL**.
- Desarrollo de aplicaciones web seguras en Flask/Django integradas con **SQL Server**, usando **HTMX** para actualizaciones dinámicas de interfaz.

### 🏡 App de Pedidos para Airbnb (Amauta Tech)
- Desarrollo de sistema web donde los huéspedes de Airbnb pueden hacer y rastrear pedidos.
- Backend en **Node.js**, frontend con **PrimeNG**, **TypeScript** y **SCSS**.
- Arquitectura orientada a servicios para asegurar escalabilidad y mantenimiento sencillo.
